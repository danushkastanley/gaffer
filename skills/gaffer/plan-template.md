# Plan: <short title>

Write this at the end of the investigation session, save it in the repository, then run `/gaffer <path>` from a session on that repository.

## Goal

What must be true when this is finished, in two or three sentences.

## Non-goals

What this change deliberately leaves alone.

## Findings

What the investigation established: causes, decisions taken, call sites, constraints, and what was ruled out. Give file paths and line numbers. The workers see only what the lead copies from here.

## Changes

The work, as outcomes rather than steps. Optionally group it into packages; name the files each one touches. The lead will merge packages that share files.

## Off-limits

Files, contracts, schemas or behaviour that must not change.

## Done when

The evidence that counts: the commands to run and what they must show, and the runtime path to exercise.

## Open questions

Anything undecided. The lead stops if a question here changes what gets built, so resolve them first or mark each one as safe to decide during implementation.
